# Project Assumptions

- User population: final-year/fresher students.
- Experience is excluded from salary prediction.
- Current goal costs come only from the supplied city_goal_costs.csv dataset.
- If Area_Type is not supplied, the mean cost across that city's available areas is used.
- Inflation: 6% annually, explicitly implemented as 0.06.
- Expected annual returns: 6%, 8%, 10% for short/medium/long horizons.
- Results are estimates for education/demo purposes.
